# Laravel Docs RAG

Small project for retrieval-augmented question answering on Laravel docs, plus an
evaluation harness to score answer quality.

## Where to start

- RAG app entry point: `search.py`
- Evaluation runner: `rag_eval/evals.py`
- Main eval guide: `rag_eval/README.md`
